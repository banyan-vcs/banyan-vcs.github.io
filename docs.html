Documentation

Seventeen documents, one repository

The design record lives with the code — every document below is a file in docs/ of the main repository. They are written in Chinese; the Chinese README and the English one are kept in parity.

00 overview
Overview

What banyan is, on one page: the architecture map and the core design judgments behind it.

01 positioning
Big picture

The positioning thesis: code storage as an independent infrastructure layer.

02 model
Data model

Directory-anchored timelines, the weaving engine, assembly-on-read.

03 storage
Storage

The pack CAS: sharding, streaming ingest, bounded-memory serving, addressing and renames.

04 compat
Git compatibility

The protocol boundary: smart HTTP and SSH, negotiation semantics, accepted deviations — each verified against real git.

05 api
Service & API

The service layer and the /api/v1 surface, plus the internal RPC plane.

06 cli
CLI

The thin .banyan workspace client — commands, semantics, and where real git takes over.

07 auth
Authorization

Repo / directory / branch granularity, personal-branch visibility, policy sources for single-node and cluster.

08 derived
Derived data

Woven views, caches and their invalidation — what is computed, what is stored, what is thrown away.

09 indexing
Indexing & packing

Generation numbers, idx v2 with 64-bit offsets, geometric repack.

10 ha
High availability

Refs service + scattered packs: failure detection, failover, replica recovery, node rejoin.

11 perf
Performance

The memory-budget system, bottleneck ledger and the measured wins — from ingest to serving.

12 demo
Docker demos

Single node and HA-cluster walkthroughs you can run in one command.

13 testing
Testing

The integration matrix philosophy: 64 cases, real git CLI, memory-constrained chains.

14 roadmap
Roadmap

Milestones: workflow, console, HA line, platform integration.

15 workflow
Workflow

The convergence merge train: queueing, server-side convergence, force-push guards.

16 bench
Benchmark report

Full comparison against a real git http-backend: bytes, wall time, and where each number comes from.

More lands in the tree as features do — browse docs/ in the repository for the live set.
